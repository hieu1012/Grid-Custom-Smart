4. rowClass + rowSelected — highlight theo điều kiện

7. Grouping — group theo cột

Bật [groupable] → mỗi header có nút group. Click nút để group the cột đó (dir lấy từ sort hiện tại nếu có). Click nút lần nữa để ungroup. Group collapse/expand phát groupExpand/groupCollapse; aggregates (sum/count) hiển thị ở group footer.

8. Filter row — lọc theo cột

[filterable]="'row'" → input dưới mỗi header. Cột số dùng operator eq, cột text dùng contains; xóa text = bỏ filter. Mỗi lần lọc phát filterChange + dataStateChange.

9. Selection — checkbox chọn dòng

[selectable]="true" → cột checkbox: header chọn tất cả trang hiện tại, row chọn từng dòng. selectionChange trả selected/deselected rows.

10. Resizable — kéo mép cột

[resizable]="true" → kéo handle ở mép phải header để đổi width cột (min minResizableWidth = 10px).

11. Column menu — sort + ẩn/hiện cột

[columnMenu]="true" → nút ⋮ trên mỗi header mở menu: sort asc/desc (phát sortChange) + list cột check/uncheck để ẩn/hiện.

Gắn [kendoGridDataBinding]="fetchProducts" → grid tự gọi hàm fetch mỗi khi state thay đổi (sort/page). Hàm trả về Promise<GridDataResult> giả lập server (delay 400ms + loading mask); ở app thật bạn gọi HTTP API tại đây.

15. autoGenerateColumns — tự sinh cột theo data

[autoGenerateColumns]="true" + không khai báo cột → grid tự tạo cột theo fields của object đầu tiên trong data (title = field name).

16. Column group — header nhiều tầng

kendo-grid-column-group bọc các cột con để header lồng nhau (rowspan/colspan tự tính).

17. Locked columns — cột cố định khi cuộn ngang

[locked]="true" → cột dính bên trái (sticky) khi table cuộn ngang; nền trắng + vị trí offset tự tính. Kéo scroll ngang để thấy hiệu ứng.

18. Column reorder — kéo thả header đổi thứ tự cột

[reorderable]="true" → giữ chuột ở header và kéo ngang để đổi thứ tự. Thả phát columnReorder với column/oldIndex/newIndex.

20. Checkbox / radio column — chọn hàng

kendo-grid-checkbox-column: header có select-all (indeterminate khi chọn một phần), row chọn nhiều. kendo-grid-radio-column: chọn đúng 1 hàng (thay thế selection hiện tại).

21. Span column — gom cột con thành 1 cell

kendo-grid-span-column gộp các cột con thành 1 cell duy nhất trong body (colspan = số cột con). Không có template → từng giá trị xếp dọc styled k-span-cell-value; có kendoGridSpanCellTemplate → render tùy biến.

22. Grid footer — aggregates (count / sum)

[aggregates] khai báo descriptor → grid footer row xuất hiện dưới @empty. Cột không có kendoGridFooterTemplate hiển thị text mặc định (vd "Count: 12"), cột có template render tùy biến (vd tổng tiền).

Sum: {{ value.sum | number: '1.2-2' }} ₫

23. Column chooser — nút ẩn/hiện cột trên toolbar

[columnChooser]="true" → toolbar hiện nút Columns, click mở popup liệt kê cột (chỉ cột có [includeInChooser]="true", mặc định đúng) với checkbox ẩn/hiện từng cột. Click ngoài popup để đóng.
